# Seiran Kernel

Automated kernel builder for **Redmi Note 13 4G/NFC (sapphire/sapphiren)** — `android13-5.15`, GKI + CLO variants.

> ⚠️ Personal project. Tested on my own device only. Flash at your own risk.

---

## Quick Start

1. Download ZIP from [Releases](../../releases)
2. Flash via OrangeFox / TWRP
3. Reboot

> Using **Magisk**? Re-patch boot image after flashing.
